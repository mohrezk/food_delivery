[1] CONFIG/FIELDS.PY (NEW)
    - LocationField: custom DRF serializer field
    - Input:  {"lat": 40.71, "lng": -74.00}
    - Output: {"lat": 40.71, "lng": -74.00}
    - Storage: PostGIS Point(lng, lat, srid=4326) — lng-first per GeoJSON

[2] ACCOUNTS/MODELS.PY (CHANGED)

    - Import changed: from django.contrib.gis.db import models

[3] ACCOUNTS/SERIALIZERS.PY (CHANGED)
    - Added location = LocationField(required=False) to UserSerializer
    - Removed lat, lng fields from UserSerializer fields list

[4] RESTAURANTS/SERIALIZERS.PY (CHANGED)
    - Added location = LocationField to RestaurantSerializer + RestaurantDetailSerializer
    - Explicit fields list instead of __all__
    - Proper read_only_fields

[5] RESTAURANTS/SEED_RESTAURANTS.PY (CHANGED)
    - Uses Point(lng, lat, srid=4326) instead of setting lat/lng floats

[6] ORDERS/MODELS.PY (REWRITTEN)
    - Status: PENDING → ACCEPTED → PREPARING → READY → PICKED_UP → DELIVERED
    - Plus: CANCELLED, EXPIRED
    - delivery_location: PointField(geography=True)
    - Status timestamps: accepted_at, preparing_at, ready_at, picked_up_at,
      delivered_at, cancelled_at
    - TRANSITIONS dict: maps each status → set of allowed next statuses
    - save() validates transition, auto-sets timestamps on transition
    - Import: from django.contrib.gis.db import models

[7] ORDERS/SERIALIZERS.PY (REWRITTEN)
    - CartItemSerializer: includes price (live) + price_snapshot (frozen)
    - CartSerializer: includes computed total
    - CheckoutSerializer: {restaurant, delivery_address, delivery_location}
    - OrderSerializer: nested items, LocationField for delivery_location,
      customer (source=user), all status timestamps

[8] ORDERS/VIEWS.PY (REWRITTEN)
    - CartView: GET /api/cart/ — view/auto-create user's cart
    - CartItemViewSet: CRUD cart items, merges quantity on duplicate,
      validates availability
    - CheckoutView: POST /api/orders/checkout/
        * Reads user's cart
        * Validates all items belong to same restaurant
        * Creates Order + OrderItems (snapshot prices)
        * Computes total, clears cart
        * Returns 201 with order
    - OrderViewSet: GET /api/orders/, GET /api/orders/{id}/
        * ReadOnlyModelViewSet, user-scoped
        * Prefetches items + menu items
    - CancelOrderView: POST /api/orders/{id}/cancel/
        * Allowed from: PENDING, ACCEPTED, PREPARING, READY
        * Rejected from: PICKED_UP, DELIVERED, CANCELLED, EXPIRED
